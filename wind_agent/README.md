# Agentic AI для прогнозирования выработки ВЭС

**Владелец кейса:** Самрук-Казына.

Проект воспроизводит кейс HackAlemAI для тестового периода **1–28 февраля 2026 года**. Каждый день система формирует почасовой прогноз нормализованной активной мощности двух турбин на следующий местный календарный день, используя архивный прогноз погоды, доступный к моменту выпуска.

## Что делает агент

`run.py` запускает последовательный цикл с отдельными инструментами и проверками:

1. Агент данных читает исходные 10-минутные CSV и агрегирует мощность, измеренный ветер и температуру до часа. Часы, где есть менее трёх измерений, исключаются из обучения.
2. Погодный агент загружает точные запуски ECMWF IFS HRES 9 km через архив Open-Meteo Single Runs API и сохраняет ответы в кэш.
3. Модель ветра обучается отдельно для каждой турбины, чтобы оценить местную скорость ветра по прогнозу модели погоды.
4. Модель мощности отдельно для каждой турбины прогнозирует нормализованную активную мощность по оценённому ветру, прогнозу ветра на 10, 80 и 100 м, порывам, направлению, температуре, часу и сезонности.
5. Агент анализа проверяет 24 часа прогноза, пропуски и границы мощности от 0 до 1. Если предпочитаемый погодный запуск недоступен, система пробует более ранние циклы и фиксирует выбор в журнале.

Это автономный инструментальный процесс с ML-моделью, состоянием, повторной загрузкой при обновлении входов и проверками результата. Для его работы не нужны LLM-сервис или закрытые API-ключи.

## Время выпуска и архивная погода

Время выпуска — **00:00, Asia/Almaty**. На дату выпуска D система прогнозирует следующие сутки, D+1, то есть использует горизонт 24–47 часов. Предпочитаемый погодный запуск — 12:00 UTC предыдущего календарного дня. Для выпуска в 00:00 по Казахстану это 19:00 UTC предыдущего дня. Если запуск 12Z недоступен, агент последовательно пробует 06Z и 00Z.

Open-Meteo хранит отдельные прогоны с указанием времени инициализации. Инициализация не равна времени публикации: для глобальных моделей сервис указывает типичную задержку выпуска 4–6 часов. Поэтому выбор 12Z к 19Z опирается на типичное время публикации; точную историческую минуту доступности архивный интерфейс не подтверждает. Инициализация, горизонт и факт резервного запуска записываются в каждой строке прогноза и в журнале агента.

Для точного воссоздания использован архив ECMWF IFS HRES. Архив отдельных запусков этой модели доступен с 14 марта 2024 года. Если отдельный погодный цикл неполон или недоступен, агент фиксирует пропуск и продолжает расчёт на пригодных циклах.

## Результаты и единицы измерения

После запуска файл прогноза содержит 24 строки на каждый рассчитанный день. Он включает прогноз каждой турбины, равновзвешенное среднее по двум турбинам, погодные входы, дату выпуска, время архивного запуска и горизонт прогноза.

В исходных данных нет номинальной мощности турбин. Поэтому `farm_average_normalized_power` — равновзвешенное среднее нормализованной мощности, а не выработка в МВт. Колонки каждой турбины сохранены отдельно, чтобы позже можно было пересчитать суммарную выработку при наличии их номиналов.

Перед февральским replay система проводит holdout-проверку на январе 2026 года. Метрики сохраняются локально в `outputs/validation_metrics_january_2026.csv`. Январская проверка не является оценкой точности февраля.

## Запуск

Требуется Python 3.10 или новее, доступный по команде `python`. На Windows из каталога проекта выполните:

```powershell
.\setup.cmd
.\start.cmd
```

`setup.cmd` создаёт `.venv`, восстанавливает отсутствующий `pip`, устанавливает зависимости и проверяет их совместимость, импорт библиотек и часовой пояс. Повторная установка использует существующее окружение. Активация через `Activate.ps1` не требуется. Пути с кириллицей и пробелами поддерживаются; скрипты можно вызывать по полному пути из другого каталога. Для установки отсутствующих зависимостей нужен интернет.

Перед первым расчётом поместите предоставленные организаторами файлы в `data/raw/` под именами:

- `turbine_1.csv`
- `turbine_2.csv`

Исходные данные турбин и погодный кэш не публикуются в GitHub. При отсутствии кэша агент загрузит архивные погодные запуски через Open-Meteo API.

Для проверки готового окружения без установки пакетов:

```powershell
.\setup.cmd --check
.\start.cmd --help
```

Первый расчёт загружает архивные погодные запуски и занимает несколько минут. Последующие запуски используют `data/cache/runs/`, но могут обращаться к API при отсутствии или неполноте кэша. Чтобы обновить погодный кэш, укажите `--refresh-weather`. Чтобы ограничить даты выпуска прогноза, например одной неделей, выполните:

```powershell
.\start.cmd --start-issue-date 2026-02-01 --end-issue-date 2026-02-07
```

Флаг `--skip-validation` пропускает январскую holdout-проверку.

На Linux/macOS: `python3 setup_env.py`, затем `.venv/bin/python run.py`.

### Если установка прервалась

После устранения причины повторите `.\setup.cmd`: скрипт продолжит установку в существующем окружении. Если окружение перенесено с другого компьютера или его Python удалён, переименуйте `.venv` и повторите установку.

При проверке в изолированной среде `ensurepip` получил `PermissionError` при записи во временную папку, а обучение — `WinError 5` при создании внутренних каналов потоков. Запуск с разрешениями на эти операции завершился успешно в том же каталоге. При такой ошибке используйте обычный терминал с нужными разрешениями; перенос проекта из пути с кириллицей не требуется.

## Файлы

- `setup.cmd`, `setup_env.py` — установка, восстановление и проверка окружения.
- `start.cmd` — запуск прогноза на Windows без активации окружения.
- `data/raw/` — каталог для двух исходных CSV турбин; файлы добавляются локально.
- `data/cache/runs/` — локальный кэш ответов Open-Meteo Single Runs API; заполняется автоматически.
- `outputs/` — локальные прогнозы, метрики, журнал агента и манифест запуска; создаются при расчёте и не публикуются в GitHub.

## Источники

- [Open-Meteo Single Runs API](https://open-meteo.com/en/docs/single-runs-api) — архив отдельных погодных запусков и описание параметра инициализации.
- [Open-Meteo Historical Forecast API](https://open-meteo.com/en/docs/historical-forecast-api) — сведения о погодных моделях и доступности архивов.
- Техническое задание и координаты взяты из приложенного DOCX. Исторические данные турбин — из двух приложенных CSV.
