# ИИ-ассистент для сайта ekt.kz

Владелец кейса — Электрокомплект. Это локальный прототип консультанта по электротехническим товарам: он читает каталог и остатки через API ekt.kz, показывает найденные характеристики, предлагает отмеченные в карточке рекомендации и спрашивает явное подтверждение перед изменением своей демонстрационной корзины.

## Запуск

Нужен Python 3.10 или новее. В проекте нет внешних Python-зависимостей.

1. Скопируйте `.env.example` в `.env.local`.
2. Заполните `EKT_API_USER` и `EKT_API_PASSWORD` учётными данными API партнёра. Локальный `.env.local` исключён из Git.
3. Запустите сервер из папки проекта:

   ```powershell
   py -3 app.py
   ```

4. Откройте `http://127.0.0.1:8000`.

По умолчанию сервер доступен только на этом компьютере. Измените `HOST` и настройте HTTPS, если потребуется демонстрация из локальной сети.

## Возможности прототипа

- Ищет товар по названию, артикулу или модели и показывает цену из API.
- Показывает описание, распознанные характеристики, сертификаты, если они отданы карточкой, и остатки по складам.
- Для аналогов использует список рекомендаций `RECOMMEND` из карточки товара; в интерфейсе это явно обозначено как рекомендация каталога.
- Отвечает, что условий оплаты, доставки и минимальной партии нет в переданном API, вместо выдумывания ответа.
- Для добавления создаёт предварительный запрос, требует нажатия «Да, добавить» и повторно проверяет остаток перед изменением демонстрационной корзины. Количество проверяется с учётом уже добавленного в сессию.
- Не собирает и не хранит платёжные данные.
- Работает на русском языке и перестраивается под мобильный экран.

В этой версии понимание запросов реализовано поиском и правилами, без внешней LLM. Это оставляет ответы привязанными к данным API.

## Архитектура

- `app.py` — сервер на стандартной библиотеке Python, Basic Auth к каталогу, ограниченный поисковый индекс, извлечение карточек товара и проверка подтверждения корзины.
- `static/index.html`, `static/styles.css`, `static/app.js` — адаптивный чат и интерфейс демонстрационной корзины.
- `.env.local` — локальные секреты и настройки; файл не следует добавлять в репозиторий.

Переданный API предоставляет `GET /products?page=N` и `GET /products/detail?id=ID`. У списка нет серверного поиска или общего числа страниц, поэтому поиск прототипа ограничен первыми страницами. По умолчанию проверяются первые 8 страниц (до 160 позиций); диапазон настраивается переменной `EKT_SEARCH_PAGES` (максимум в прототипе — 100 страниц). Для производственного поиска по всему каталогу партнёру нужно предоставить поисковый параметр, выгрузку каталога или API индексации.

## Границы интеграции

Данные партнёра содержат только читающие методы каталога и остатков. В них нет операций записи в корзину, привязки к веб-сессии клиента или оформления заказа. Поэтому этот проект показывает состояние собственной временной корзины прототипа; она очищается при перезапуске сервера и не передаётся на сайт ekt.kz. Для полного сценария нужен согласованный API/SDK корзины сайта, проверка пользовательской сессии и URL оформления, который сохраняет выбранные товары.

В переданной карточке нет поля сертификата. Приложение выдаст ссылку только если сертификат или документ действительно присутствует в ответе API. Условия оплаты, доставки и минимального заказа также отсутствуют. В прототипе принимается текст; разбор Excel, Word, PDF и JPEG из информационного пакета пока не подключён.

## API прототипа

- `GET /api/health` — доступность конфигурации.
- `GET /api/cart?session=...` — состояние текущей демонстрационной корзины.
- `POST /api/chat` — поиск и ответ по каталогу.
- `POST /api/cart/prepare` — проверка товара и создание запроса на добавление, без изменения корзины.
- `POST /api/cart/confirm` — повторная проверка остатка и добавление только при `confirmed: true` и совпадающем одноразовом токене.
- `POST /api/cart/cancel` — отмена ожидающего добавления.

Сервер не пишет Basic Auth в логи и не передаёт его браузеру. Внешний сервер пока не следует открывать в интернет: прототип не заменяет авторизацию и защиту пользовательской сессии сайта.
